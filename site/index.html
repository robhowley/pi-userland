Install from npm into Pi.

Copy a command below and run it in your terminal.

Before you install

  • Pi — All packages install into Pi and expect Pi extension support.
  • Merge Ready — Requires git and authenticated gh; check with gh auth status.
  • OpenRouter — Set OPENROUTER_MANAGEMENT_KEY or OPENROUTER_API_KEY.
  • Optional Toolbelt — The iTerm2 Python API is only for Session Deck’s optional Toolbelt; /session-deck does not require iTerm2 setup.
